# OSI Model – Networking from Layer 7 to Layer 1

## About This Project

This repository is a learning project focused on understanding the Open Systems Interconnection (OSI) model and how computer networks communicate.

The project covers all seven layers of the OSI model, starting from the Application Layer (Layer 7) and moving down to the Physical Layer (Layer 1).

## Project Objectives

- Understand the purpose and functionality of each OSI layer.
- Study networking protocols and technologies associated with each layer.
- Understand how data travels through a network.
- Explore real-world networking examples.
- Perform practical networking experiments using different tools.
- Document configurations, commands, and technical concepts.

## OSI Model Layers

| Layer | Name |
|---|---|
| 7 | Application Layer |
| 6 | Presentation Layer |
| 5 | Session Layer |
| 4 | Transport Layer |
| 3 | Network Layer |
| 2 | Data Link Layer |
| 1 | Physical Layer |

## Tools and Technologies

- Cisco Packet Tracer
- Windows Command Prompt
- Wireshark
- Networking protocols and utilities

## Project Structure

Documentation for each layer will be maintained in its own directory. Practical experiments and additional learning resources will be documented separately.

## Learning Approach

Each layer will include theoretical explanations, important protocols, real-world examples, technical commands, and practical experiments where applicable.
