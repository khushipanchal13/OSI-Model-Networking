# OSI Layer 7 – Application Layer

## Project Overview

This section demonstrates the Application Layer (Layer 7) of the OSI Model through practical networking activities using Cisco Packet Tracer.

The purpose of this project is to understand how network applications and services communicate between client devices and servers.

## Lab Objectives

- Understand the role of the Application Layer.
- Configure common network application services.
- Understand client-server communication.
- Configure DNS, DHCP, HTTP, HTTPS, FTP, SMTP and POP3.
- Explore Telnet, SSH, SNMP, TFTP and NTP.
- Test network services from client computers.
- Identify common application-layer problems.

## Technologies and Tools

- Cisco Packet Tracer
- Cisco 2911 Router
- Cisco 2960 Switch
- Server-PT
- PC-PT
- Cisco IOS CLI

## Lab Components

This lab uses one router, one switch, four servers and four client computers.

The servers provide network services, while the client computers access and test those services.
